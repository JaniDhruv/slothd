# slothd
🦥 The Sloth Daemon: an air-gapped, local-first AI file tidier that runs only when your system is idle. Uses Gemma 3 Vision &amp; structured outputs to read PDFs, receipts, and screenshots, sort ~/Downloads into clean folders, and power "Where is my...?" vector search via Tiger Data pgvector—at $0 cloud cost and 100% privacy.
